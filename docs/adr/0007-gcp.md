# ADR 0007: GCP serverless control plane without Kubernetes

Status: accepted, 2026-07-25.

Staging and production are separate GCP projects. Cloud Run hosts web, API, and
worker; Cloud SQL PostgreSQL provides HA/PITR; Memorystore Standard backs
ephemeral operations; Direct VPC egress connects private services. Migrations
run as a gated Cloud Run Job. Workload Identity Federation replaces static
cloud keys. The default region is `europe-central2` and remains a Terraform
variable.
