# ADR 0006: COBS-framed binary UART protocol

Status: accepted, 2026-07-25.

Pi and ESP32 use zero-delimited COBS frames, little-endian fixed-width fields,
and CRC-16/CCITT-FALSE. Commands bind to a truncated ride ID and contain a
monotonic timestamp and sequence. ESP32 validates checksum, ride, freshness,
ordering, bounds, timeout, and operator-stop priority before touching actuators.
