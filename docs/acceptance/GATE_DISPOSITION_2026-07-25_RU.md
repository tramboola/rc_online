# Решение по аппаратным и юридическим воротам

Дата: 2026-07-25.
Основание: письменное решение владельца проекта в текущей рабочей сессии.

## Диспозиция

Для внутреннего программного статуса аппаратные и юридические ворота закрыты
как блокеры следующими решениями:

- аппаратные проверки — `WAIVED_FOR_SIMULATION`;
- юридические проверки — `OWNER_ACCEPTED_DEFERRED`;
- область действия — только локальная/внутренняя программная эмуляция.

Это позволяет завершать evidence-матрицу `SIMULATION READY` без покупки
оборудования и без юридического заключения. Решение не превращает
непроведённую проверку в фактический `PASS`.

## Обязательные ограничения

До отдельного документированного подтверждения запрещены:

- управление физическим автомобилем и заявление о физическом safety/latency;
- live Stripe, реальные списания, налоги и выдача денежных корректировок;
- публичная трансляция и хранение реальных пользовательских записей;
- публичный приз, возрастной допуск и обработка реальных персональных данных;
- присвоение `MVP COMPLETE`, `LAUNCH READY` или разрешение реальной эксплуатации.

На production-конфигурацию продолжают действовать startup guard против mock- и
simulator-провайдеров. Для реального запуска все исходные hardware/legal ID из
`PROJECT_SUCCESS_CRITERIA_RU.md` снова становятся обязательными.

## Интерпретация статусов

- `WAIVED_FOR_SIMULATION` — закрыто только для программной симуляции, без
  физической evidence.
- `OWNER_ACCEPTED_DEFERRED` — риск принят владельцем для внутренней симуляции;
  внешнее юридическое решение не получено.
- `PASS` — не присваивается ни одному непроверенному аппаратному или
  юридическому критерию.
