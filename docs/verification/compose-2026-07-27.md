# Full Compose verification — 2026-07-27

## Scope

The complete local stack was built and started with:

```text
docker compose -f infra/compose/compose.yaml \
  --profile core --profile sim --profile obs up -d --no-build
```

Docker Desktop reported `running`; client and server were both `29.6.2`.
All external images and the five RC Racing application images were available
locally.

## Database migration

verification and exited with code 0. The `schema_migrations` table contains:


`schema_migrations` relation and still exited with code 0.

## Defects found and fixed during the first integrated start

- Excluded browser profiles and QA artifacts from the Docker build context.
- Corrected two malformed Compose `tmpfs` option lists.
- Embedded the pinned pnpm `10.33.0` runtime in read-only Node images.
- Added the minimum `NET_BIND_SERVICE` capability required by Coturn.
- Added `DAC_OVERRIDE` for Redis entrypoint traversal of its persisted
  uid-999-owned AOF directory.
- Replaced the Swagger static UI registration with dependency-free OpenAPI JSON
  endpoints at `/openapi` and `/openapi.json`.

No database or Redis volume was deleted while applying these fixes.
